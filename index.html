02 / Web platform

CONCERT BOOKING

View on GitHub →

Designed a relational database schema for events, venues, seats, bookings, vouchers, ticket inventory, payments, and attendees using Prisma ORM. Implemented customer-facing APIs for creating bookings, applying vouchers, checking booking status, and retrieving booking details. Built concurrency-safe booking logic with database transactions and atomic conditional updates to prevent ticket overselling. Added idempotency handling with a unique idempotency key, Redis locks, and caching to prevent duplicate bookings caused by request retries, while also caching booking lookup APIs for read-heavy workloads.

Node.js Express.js Prisma PostgreSQL Redis Supabase Postman
